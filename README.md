# Planet One

موقع تعريفي لشركة إنتاج أفلام وثائقية. ثنائي اللغة (إنجليزي / عربي) مع تصميم سينمائي.

## التطوير المحلي

تحتاج Node.js، ثم:

```sh
npm i
npm run dev
```

أو باستخدام Bun:

```sh
bun install
bun run dev
```

## الصفحات

- `/` — الصفحة الرئيسية
- `/films` — كتالوج الأفلام
- `/films/:slug` — صفحة فيلم
- `/about` — من نحن
- `/contact` — اتصل بنا
